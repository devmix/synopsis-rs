# Introduction

**Synopsis** is a local RAG + knowledge-graph **MCP server in Rust** — a single binary that provides **structured information to AI agents via the Model Context Protocol (MCP)**. No external services, no cluster, nothing to operate: it is built for a 16 GB laptop.

## Where Synopsis fits

Synopsis is **one stage of a larger information pipeline**, not a standalone assistant. The input is your documents (Markdown, JSON, web pages); the output is access to processed and analyzed data via MCP. Upstream, raw data is collected and normalized; downstream, an AI agent does the reasoning. Everything in between belongs to Synopsis:

![Synopsis architecture](/img/architecture.svg)

- **Upstream (outside Synopsis)** — documents are collected and normalized to supported formats (Markdown, JSON, web pages)
- **Inside Synopsis** — parse → chunk → embed (local ONNX) → NER → entity/fact extraction → cross-domain entity linking → knowledge graph + hybrid search index; the result is served as 12 read-only MCP tools
- **Downstream (outside Synopsis)** — AI agents (Claude, Cursor, any MCP client) call the MCP tools to retrieve chunks, entities, facts, and graph neighborhoods; the agent does the reasoning

Each stage in detail: [The Pipeline](./concepts/pipeline).

## Key capabilities

- **Hybrid search** — lexical (SQLite FTS5) and semantic (vector) retrieval fused with Reciprocal Rank Fusion, plus recency/authority reranking
- **Knowledge graph** — entities, facts, and relations: NER via ONNX, LLM-based cross-domain entity linking, CEL linkers, a petgraph index
- **MCP server** — 12 read-only tools over Streamable HTTP (`/mcp`), with the legacy HTTP+SSE transport (`GET /sse` + `POST /message`) also served, plus `GET /health`
- **Disk-backed ANN** — usearch HNSW (mmap, scalar-quantized, WAL + segments); the query path never loads the embedding model
- **Self-contained build** — SQLite/FTS5 compiled in-tree (bundled), no system dependencies; the ONNX runtime library and model weights are downloaded by the binary on demand (verified by URL + size + SHA-256)
- **Event task queue** — a background worker keeps the index up to date: startup reconcile, a file watcher, and the pipeline enqueue events (`doc:index` / `doc:delete` / `entity:link`), the worker processes them

## What Synopsis is not

- **Not a full GraphRAG/KnowledgeRAG platform.** Synopsis deliberately focuses on a single job: turning documents into a queryable, structured knowledge base for AI agents — with zero infrastructure.
- **Not a data-cleaning or ETL stage.** The pipeline input is assumed to arrive clean and normalized; prepare your documents before ingesting them.
- **Not a chatbot or reasoning engine.** Synopsis exposes the knowledge base through tools; the connected agent does the reasoning.
