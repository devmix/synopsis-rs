## Legacy vec0 tables — expected to be ignored without error

The DB still contains the old SQLite-vec0 vector store from before the
Rust-side rebuild:

- `chunks_vec` — `CREATE VIRTUAL TABLE chunks_vec USING vec0(chunk_id INTEGER PRIMARY KEY, vector FLOAT[384])` (legacy **384-dim** embeddings; current bge-m3 vectors are 1024-dim and rebuilt from chunk text, never read from here)
- shadow tables: `chunks_vec_chunks`, `chunks_vec_info`, `chunks_vec_rowids`, `chunks_vec_vector_chunks00`

This is a real-world instance of the data-schema contract "old vec0 tables are
ignored without error": opening this file and running FTS5 queries must work in
their presence. The one-shot probe (`cargo run -p spikes --bin probe_db`) and
spike S1 (task 1.1) both assert exactly that.

## Verification probe

One-shot rusqlite check inside the temporary `crates/spikes` crate (acceptance
criterion of task 0.1): opens this file read-only, verifies the expected table
set (including FTS5 shadow and legacy vec0 families), migrations `1..=5`,
row counts, a bm25-ordered FTS5 MATCH query returning finite scores, and
`PRAGMA integrity_check`:

```sh
cargo run -p spikes --bin probe_db            # defaults to fixtures/knowledge.db (repo root)
cargo run -p spikes --bin probe_db <path>     # or an explicit path
```

## Regeneration at scale (not done for this change — decision, revision 1 of task 0.1)

This fixture is a copy of the existing Oracle DB on purpose: generating via
`load-test --scale medium` was skipped to avoid ~2.3 GB model download + 1–3 h
of vectorization; large-scale fixtures are deferred to the first modular change
(non-goal of `native-seam-spikes`). For future scale regeneration, per
`../synopsis/site/docs/guides/load-testing.mdx`:

```sh
cd ../synopsis && ./bin/synopsis --db /tmp/loadtest.db load-test --scale medium
```

Never run it against the production `knowledge.db`; in `mode: local` the
embedding model must already be downloaded. Scales: small = 500 docs / 10k
chunks (default), medium = 5,000 / 100k, large = 10,000 / 200k; deterministic
per `--seed` (default 42) within one Go build.
