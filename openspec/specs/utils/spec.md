# utils Specification

## Purpose

Общий крейт утилит для кросс-кратных хелперов, не принадлежащих доменному крейту; лист зависимости. Модуль temporal — единственная точка работы с датой/временем в проекте поверх jiff.

## Requirements

### Requirement: Общий крейт утилит

Крейт `crates/utils` — дом для кросс-кратных хелперов; лист зависимости (не зависит от внутренних крейтов, любой крейт может использовать). Модуль `temporal` — единственный источник работы с датой/временем; рукописные реализации календарной математики и парсинга временных меток запрещены.

#### Scenario: Единственная точка входа
- **WHEN** любому крейту нужна конвертация/парсинг/форматирование дат
- **THEN** используется `utils::temporal`, а не локальные хелперы

### Requirement: Temporal API поверх jiff

Модуль temporal тонко оборачивает jiff (default-features выключены, только std): `now_rfc3339`, `format_rfc3339(SystemTime)`, `format_backup_stamp(SystemTime)` (шаблон `%Y-%m-%dT%H-%M-%S-<ms>` UTC для имён VACUUM-снимков, инфаллибельный с клампом к эпохе), `normalize_to_rfc3339(&str)` (принимает RFC3339 и SQLite-лейаут `YYYY-MM-DD HH:MM:SS` как UTC), `parse_epoch_seconds(&str) -> Option<i64>`. Некорректный/пустой ввод → None без паник; shape-gate сохраняет строгое множество приёма заменённого рукописного парсера.

#### Scenario: Два принимаемых формата
- **WHEN** на вход поданы `2026-08-25T10:00:00Z` и `2026-08-25 10:00:00`
- **THEN** оба нормализуются в один RFC3339-вывод / один epoch-результат

#### Scenario: Мусорный ввод
- **WHEN** на вход подана пустая строка или не-дата
- **THEN** возвращается None, паники нет

### Requirement: Полное покрытие миграции

Весь код проекта использует utils::temporal для дат; рукописные реализации отсутствуют во всём workspace (search enrich/rerank, ingestion parsers/backup, embedding library — мигрированы, выходные строки байт-идентичны, потребительские ассерты не менялись).

#### Scenario: Grep-гейт рукописного кода
- **WHEN** workspace проверяется на идентификаторы рукописных реализаций (civil_from_days, rfc3339_from_secs и пр.)
- **THEN** совпадений в коде нет
